# Choose your path

You don't need the whole book — you need the chapters that match your situation. Find yourself below and follow the sequence.

## "I'm launching a SaaS product"

You need day-one visibility on all three surfaces, in the right order — foundations before amplification.

1. [Launch a SaaS product](../playbooks/saas-launch.md) — the full sequence, start here
2. [Google Search Console](../google/search-console.md) + [Bing Webmaster Tools](../bing/bing-webmaster-tools.md) — measurement first
3. [Structured data](../google/structured-data.md) and [Rich results](../google/rich-results.md) — the SaaS schema graph
4. [Keyword and SERP strategy](../google/keyword-strategy.md) — especially if your brand name contains generic words
5. [Content that gets cited](../ai-search/content-that-gets-cited.md) — the intent-query content cluster
6. [The MCP Registry](../agents/mcp-registry.md) — if you have an API or MCP server, register it

**Case study to read:** [customdomain.ai](../case-studies/customdomain-ai.md)

## "I run a local business"

The local stack is its own discipline: map pack, reviews, and honest local pages beat generic SEO.

1. [Launch a local business](../playbooks/local-business.md) — the full sequence
2. [Google Business Profile](../google/business-profile.md) — the single highest-impact local surface
3. [LocalBusiness schema graph](../local/local-business-schema.md) → [FAQ schema](../local/faq-schema.md) → [Reviews](../local/reviews.md)
4. [Service-area pages](../local/service-areas.md) — pages that survive scrutiny
5. [Authenticity audits](../local/authenticity.md) — before someone else audits you
6. [AI crawlers](../ai-search/ai-crawlers.md) — make sure ChatGPT and Perplexity can even read your site

**Case study to read:** [Heads Up Outdoor Services](../case-studies/headsup.md)

## "ChatGPT / Perplexity never mentions us"

Being invisible to AI is usually a retrievability problem, a content problem, or both.

1. [The 30-minute AI visibility audit](../playbooks/ai-visibility-30min.md) — diagnose first
2. [How AI finds and cites](../foundations/ai-retrieval.md) — understand the mechanics
3. [GEO fundamentals](../ai-search/geo-fundamentals.md) — the levers that actually move citations
4. [AI crawlers and crawlability](../ai-search/ai-crawlers.md) — the most common silent blocker
5. [Content that gets cited](../ai-search/content-that-gets-cited.md) + [Off-site signals](../ai-search/offsite-signals.md)
6. [Auditing your AI visibility](../ai-search/ai-visibility-audit.md) — set the re-audit cadence

## "My site isn't indexed / is indexed wrong"

Indexing problems are almost always infrastructure problems wearing an SEO costume.

1. [Sitemaps and robots.txt](../google/sitemaps-and-robots.md) — check the basics and the noindex trap catalog
2. [Reverse proxies and CMS traps](../technical/reverse-proxy-cms.md) — if your CMS sits behind nginx/Cloudflare
3. [Rendering, WAFs, and bot challenges](../technical/rendering-and-waf.md) — if bots get challenged, you're invisible
4. [Google Search Console](../google/search-console.md) — URL Inspection tells you what Google actually sees
5. [Domain migrations](../technical/domain-migration.md) — if this started after a domain change
